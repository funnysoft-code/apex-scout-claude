# Apex Scout for Claude

Find track days in Europe from Claude. This plugin connects Claude to the Apex Scout track day finder at https://apexscout.app/mcp and adds a skill, find-a-track-day, that guides Claude to ask for your country, Circuit and dates, then list each Listed Day with its date, organiser, price and link.

Booking always happens on the organiser's own site. There is no sign-in and the plugin collects no personal data; the connector is read-only.

Help: https://apexscout.app/en/help/claude. Support: hello@apexscout.app.
